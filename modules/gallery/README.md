# Infinite Portfolio Gallery — 12 px corner version

Identical intended layout and motion to version 2, but with **12 px rounded
corners on the images** (including while they scale as full cards on hover).
Designed to fill a 1602 × 710 Figma Code Layer.

- All 25 artworks, original proportions, 250 px width.
- 58 px horizontal and 54 px vertical masonry gaps.
- Smooth infinite two-direction dragging with momentum.
- Entire image scales 1.12× on hover, without inner cropping.
- No gallery zoom, no captions or overlays.
- Original uploaded maroon-purple gradient background.
