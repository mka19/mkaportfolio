# Khaif — locked Code Layer v8

Drop/import this runnable HTML project as **one** Figma Code Layer. Do not place it on top of earlier versions; hide the previous Code Layers first if they still exist.

## Locked dimensions and colors

- Character: fixed 123px height; 21px bottom; X offset -35px; start inset 13px; end inset -56px; walk amount 1.
- Slider: 259px wide; 4px bottom; X offset 0; dot scale 1; active ring 1.2; corner radius 4.
- Slider base: #0f0f0f; untouched dots: #292929; reached dots: #f4f4f0; slightly larger 3D-gradient active ball.
- Smoke: #aebbc2; scale 1; X 0; Y 0.
- Canvas background: transparent. No designer EDIT panel or drag controls.

## Interaction

1. At first, the illustrated character is absent. The slider alone is visible.
2. First hover brings a toddler following the cursor. Click the stage to settle the toddler; dragging the slider also unlocks the sequence.
3. Slide through the life stages. Only one adult-body layer is displayed once the cigarette gesture starts.
4. The adult lifts the cigarette, exhales flowing smoke, which takes the shape of **HIRE ME**, dissolves, then reforms as a floating heart on the second puff.

This is a browser-rendered Code Layer, not an editable vector animation. The actual appearance of a transparent background can still be affected by the Figma preview surface and overlapping existing layers.
